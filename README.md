# 阿纳克实时计分（Arnak Live Scorer）

BGA《失落的阿纳克遗迹》计分插件 v0.9.15。常驻浮窗显示所有玩家实时终局分，基础版（鸟庙/蛇庙），不含扩展。**支持对局、观战、回放三种模式**。

> v0.9.8 = v0.9.7 + 中文购买/打出措辞按真实日志修正（`将X放到其牌堆的底部` / `打出X`，修正前买牌不入账）。

## 安装

1. 浏览器装 Tampermonkey（Chrome/Edge）
2. 新建脚本，粘贴 `arnak-scorer.user.js` 全文
3. 打开 BGA 阿纳克对局/观战/回放，浮窗自动出现（其他游戏静默）

## 功能

- **计分模型**：全部官方数据或实战验证（卡表、研究轨含顶格 rank 制、神像槽位、守卫、板块、恐惧）
- **三种模式**：对局 / 观战 / 回放，页脚显示当前模式
- **观战/回放**：玩家身份按字符串归一，标签按座位固定顺序；“（我）”只标观看者本人（观战时不标任何人）
- **完整牌库**：彩色 chips（资金黄/探索绿/物品褐黑字/神器蓝/恐惧灰），含初始牌移除追踪；终局列表名为「已见牌库」（它只是日志与可见区里“见过”的牌，与总分同为插件自算）
- **日志补全**（中/英界面）：对局/观战/回放统一走日志账本，补全"买过没打出"的牌库盲区；卡牌身份读日志里的隐藏标记（语言无关），动作按跨语言词元判定（日志可能中英混排）
- **结算校准**：scoreBreakdown 存在时恐惧/卡牌分用官方值覆盖
- **UI**：苹果质感玻璃浮窗、深浅主题（首开跟随系统）、胶囊玩家标签（**我排最左，其余按座位序**，不随分数换位）、迷你图标（可拖动）、完整牌库展开

## 数据读取架构

```
数据源    gameui.gamedatas（官方状态镜像）+ DOM（快照字段）+ 日志（牌库历史）
计分      官方表 + 实测反推规则；终局 showAllCards 全量重灌 / scoreBreakdown 校准
日志补全  购买（底部/顶部）、打出、恐惧获得/移除、初始牌移除；时间顺序、撤销重建
语言分包  LOG_PACKS[zh|en]：同一套动作槽位两套措辞；卡名反查内置中/英两张表（同序）
hook      游戏原生 notif（exileCard/gainFear/showAllCards），日志模式让位防双计
```

## 关键数据（官方源码 + 实战验证）

- 卡牌分值表：40 item + 35 art（tooltips.js cardPoints）
- 研究轨：行 0-7 官方表；**放大镜顶格按到顶顺序 23/21/20/19**；笔记本顶格 = 行 7 分（蛇 15 鸟 10）
- 神像：(idol + 4 − idol_slot) × 3 + 空槽分 [0,4,7,9,10]
- 守卫 DOM 计数 × 5；板块 铜 2/银 6/金 11；恐惧 −1/张

## 已知边界

- **界面语言**：日志措辞分包（zh / en）。中文为原版实测校准；英文已按真实英文对局日志逐条核对（见 docs/log-fixture-en.html）
- **中文界面**：购买是 `将X放到其牌堆的底部`（`放到`，且名字与「将」之间无空格），打出是 `打出X`。名字前缀与时间戳分别处理
- **英文句子别照中文反推**：买牌是 `puts X to the bottom of their deck`，起始玩家是 `receives the start player marker`，恐惧是 `gains a fear`，撤销是 `cancels their move`
- **BGA 的 `players` 里没有 `id` 字段**：实测对局、观战两神视图都一样（`current_player_id` 也没了），真实 id 只在 `players` 的**键**上（如 `"96725718"`）。玩家身份一律优先 `p.id`、取不到退回键，并统一成字符串；否则所有人落到同一个 `undefined` 上（牌库并成一个、`#player_board_undefined` 选择器全落空、守卫分归零）
- **BGA 隐私**：对手手牌/牌库界面不可见，靠日志补全解决"买过没打出"部分
- 扩展（Expedition Leaders）不支持

## 文件

```
arnak-scorer.user.js   油猴脚本（单文件，直接安装）
EXPERIENCE.md          BGA 桌游计分插件开发方法论（可复用到其他游戏）
HANDOFF.md             交接备忘（归档后续接从这里开始）
docs/arnak.js          BGA 游戏客户端源码（数据表提取自其中）
docs/tooltips.js       官方数据词典（卡表/轨道分/idol 分）
docs/*.py              下载与解析脚本（开发期工具）
docs/log-fixture-en.html  英文日志回归样本（真实对局日志，改措辞后先跑这页）
docs/log-fixture-zh.html  中文日志回归样本（真实中文对局日志，关键在「将X放到…」「打出X」）
docs/mixed-fixture.html   中英混排回归样本（`puts 火把 to the 底部 of their deck`）
docs/undo-fixture.html    撤销语义回归样本（打出的牌被撤销后必须留下）
docs/spectator-fixture.html  观战视图回归样本（真实观战数据：players 无 id，键才是 id）
docs/harvest-snippet.js   对账采样器（F12 粘一段，自动把数据复制到剪贴板）
```

> `docs/arnak.js`、`docs/tooltips.js` 是 BGA 的游戏源码与数据，**不入库**；需要时用 `docs/download*.py` 自行再取。
